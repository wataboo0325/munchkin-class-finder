# クラス診断 — ダンススタジオマンチカン

保護者が「うちの子はどのクラス？」を数十秒で判断し、そのまま無料体験の予約へ進めるための診断ページ。
サーバー処理・外部APIは一切使わない静的なHTML+JSのみ。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 診断本体。クラス一覧のデータもこの中に入っている（1ファイル完結） |
| `widget.js` | サイト右下に出るボタンと吹き出し。押すと `index.html` をパネルで開く |

## サイトへの設置

全ページに次の1行を入れるだけ。

```html
<script src="https://wataboo0325.github.io/munchkin-class-finder/widget.js" defer></script>
```

- パネルを開くまで診断ページを読み込まないので、サイトの表示速度に影響しない
- スマホでは画面下部の固定バーに重ならない位置に出る
- `Esc` キーまたはボタン再押下で閉じる

## クラスを追加・変更するとき

`index.html` 内の `<script id="class-data" type="application/json">` の中を編集する。**質問や分岐のコードは触らない。**

```json
{"studio":"西田辺","day":"月","time":"16:25–17:15","name":"KIDS GIRLS HIPHOP 入門",
 "teacher":"SHIZUKU","genre":"GIRLS HIPHOP","level":"入門","min":50,"id":40}
```

| キー | 意味 |
|---|---|
| `level` | `幼児` / `入門` / `初中級` / `上級` / `大人` / `その他`。これを書けば対象年齢は自動で決まる |
| `for` | 対象を明示したいときだけ（例 `["elementary","teen","adult"]`）。`その他` は必須 |
| `hidden` | `true` にすると診断結果に出さない（講師判断で案内するクラスなど） |
| `min` | レッスンの分数。月謝はここから自動計算される |
| `id` | 予約システム側のプログラムID。予約リンクの生成に使う |

スタジオを増やすときは `studios` に1行足す。

## 回答データの記録（任意）

`index.html` の `TRACK_URL` にGoogle Apps ScriptのウェブアプリURLを入れると、選ばれた選択肢と結果件数がスプレッドシートに記録される。空のままなら何も送信しない。個人情報は取得しない。
